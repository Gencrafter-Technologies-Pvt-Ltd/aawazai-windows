# AawazAI for Windows: website download

This repository holds only the **releases** of the AawazAI Windows app installer downloaded from the website (`AawazAI-Setup-<version>.exe`, `latest.yml` and the `.blockmap`).

- Installed copies check these releases and update themselves (electron-updater, GitHub provider).
- The app's source lives in the main AawazAI repository (`apps/windows`). Releases are published from there with `npm run release`.
- Most people should install from the **Microsoft Store**: https://apps.microsoft.com/detail/9NL32SKFS2V6. The Store copy updates through the Store.

No source code is kept here.
